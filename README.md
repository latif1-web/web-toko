Sebuah web e-commerce yang di rancang untuk penjualan barang melalui online. 
Masyarakat lebih mudah membeli tanpa datang langsung ke toko offline, lebih hemat waktu dan tenaga karena bisa membandingkan harga serta mencari produk dari rumah, pilihan produk yang sangat beragam, serta kemudahan dalam pembayaran dan pengiriman.

Di dalam web tersebut di sajikan berbagai macam fitur :

1.Di header ada judul nama toko nya dan di bawah nama toko tersebut ada navigasi nya.

2.Di bagian katalog nya terisi bebarbagai macam-macam barng yang di jual.

3.Di sebelah kanan katalog ada promo untuk setiap barang yang di jual. 

4.Di paling bawah footer informasi lengkap dari toko tersebut.
